# HUD (hotbar, crosshair, version tag)

In-game heads-up display: crosshair, hotbar, health/hunger, and the build version
tag bottom-right.

## Vanilla specs

- Crosshair center; 9-slot hotbar; health 10 hearts (20 HP, rows of 10) above
  hotbar left, hunger 10 drumsticks right; armor icons above hearts; XP bar +
  level number; air bubbles underwater; boss bar top; subtitle/actionbar
  toast area.

## Our implementation

| Concern | Where |
|---|---|
| HUD component | `src/components/gui/HUD.tsx` |
| Hotbar slots | `src/components/gui/HUD.tsx` (reads `InventoryCore` hotbar) |
| Build/version tag | `src/buildTag.ts` (`VERSION`, `BUILD_TAG`) generated by `scripts/gen-build-tag.mjs`, shown bottom-right |

## Deviations / limitations

- Health/hunger bars are simplified vs vanilla hearts/hunger.
- Version tag is the canonical place to read current build (auto-bumped on build).

## Ruleset when modifying

- `src/buildTag.ts` is generated — never hand-edit; change via `npm run build`.
- Hotbar count must match `INV_HOTBAR_SIZE` in `src/game/inventory.ts`.
- Gate: `npm run kb:check`, `npm run build`.
